## Descrição do projeto

Site pessoal de currículo/portfólio, composto por 5 páginas HTML interligadas por um menu de navegação comum, estilizadas exclusivamente com CSS3 puro (sem frameworks) e sem uso de JavaScript. Toda a interatividade — menu mobile e estilização de campos de formulário — é feita apenas com HTML e CSS (pseudo-classes `:checked`, `:hover`, `:focus`, seletor de irmão adjacente `+`, etc.).

### Como visualizar

Basta abrir o ficheiro `index.html` num navegador. Não é necessário nenhum servidor, instalação ou dependência — é HTML e CSS puros.
